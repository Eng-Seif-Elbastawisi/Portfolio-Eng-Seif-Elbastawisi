# Seif Elbastawisi — Updated Portfolio

This folder contains the updated static portfolio website.

## Run locally
Open `index.html` in a browser. The site uses CDN-hosted Font Awesome, Google Fonts, and Swiper assets.

## Files
- `index.html` — portfolio page
- `cv.html` — CV page with PDF export
- `css/style.css` — styles and responsive/accessibility refinements
- `js/script.js` — interactions, theme toggle, navigation, filters, chatbot, and contact mailto flow
- `img/profile.jpg` — existing profile image

## Before publishing
1. Review the dates, role descriptions, links, and project details to ensure they are still accurate.
2. Test the site on a phone and desktop.
3. Upload/replace the repository files and allow GitHub Pages to rebuild.

The contact form opens the visitor's default email application; it does not submit to a backend service.

## Recent improvements
- Featured Projects now uses a responsive grid with working Native / React / Vue filters, live project counts, an accessible results announcement, and a reset state when a category has no projects yet.
- Added mobile hero top spacing to prevent overlap with the fixed navigation bar.
- Added a keyboard-accessible skip-to-content link and basic Open Graph metadata.
